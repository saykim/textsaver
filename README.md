# Text Saver

> **현재 버전: v2.4.4**

"Text Saver"는 반복적으로 사용하는 텍스트 스니펫, 코드 조각, 프롬프트 등을 손쉽게 저장하고 웹 페이지 어디에서나 `//` 단축키로 빠르게 불러와 자동 완성할 수 있는 크롬 확장 프로그램입니다.

## 🚀 주요 기능

- **✍️ 텍스트 스니펫 관리**: 제목, 내용, 태그를 포함한 텍스트를 저장, 수정, 삭제할 수 있습니다.
- **⭐ 북마크**: 자주 사용하는 중요한 텍스트를 북마크하여 별도로 관리할 수 있습니다.
- **🔍 강력한 검색**: 저장된 모든 텍스트를 제목, 내용, 태그 기준으로 빠르게 검색할 수 있습니다.
- **⚡ `//` 자동 완성**: 웹 페이지의 입력창(textarea, input 등)에서 `//`와 함께 키워드를 입력하면, 저장된 텍스트를 검색하고 선택하여 즉시 삽입할 수 있습니다.
- **📌 사이드 패널**: (v2.4.2 New) 브라우저 사이드 패널에서 더 넓은 화면으로 텍스트를 관리할 수 있습니다. 마우스 오른쪽 클릭 → 'Text Saver 사이드 패널 열기'로 실행합니다.
- **☁️ 구글 드라이브 백업**: 저장된 데이터를 본인의 구글 드라이브에 안전하게 백업하고, 다른 기기에서 복원할 수 있습니다.
- **🌐 엣지(Edge) 브라우저 지원**: 크롬뿐만 아니라 마이크로소프트 엣지 브라우저에서도 구글 로그인 및 백업 기능을 완벽하게 지원합니다.
- **🖱️ 컨텍스트 메뉴로 저장**: 웹 페이지에서 텍스트를 선택하고 마우스 오른쪽 버튼을 클릭하여 'Text Saver로 선택 내용 저장' 메뉴를 통해 해당 텍스트와 페이지 URL을 바로 저장할 수 있습니다.
- **⌨️ 단축키 지원**: `Cmd+Shift+T` (Mac) 또는 `Ctrl+Shift+T` (Windows) 단축키로 `//` 자동 완성 기능을 빠르게 켜고 끌 수 있습니다.
- **💾 데이터 관리**: JSON 파일 내보내기/가져오기 및 전체 초기화 기능을 제공합니다.
- **🤖 기본 프롬프트 제공**: CoT, ToT, ReAct 등 유용한 프롬프트 엔지니어링 템플릿이 기본으로 제공되며, 언제든지 복원할 수 있습니다.
- **📝 자동 저장**: 팝업창에서 텍스트 작성 시 내용이 자동으로 임시 저장되어, 예기치 않게 창이 닫혀도 데이터를 보호합니다.

## 📖 사용 방법

### 1. 텍스트 저장하기
- 확장 프로그램 아이콘을 클릭하여 팝업을 엽니다.
- '저장' 탭에서 제목, 내용, 태그(쉼표로 구분)를 입력하고 '저장하기' 버튼을 클릭합니다.

### 2. `//` 자동 완성 사용하기
1. 웹사이트의 텍스트 입력창에 `//`를 입력합니다.
2. 이어서 찾고 싶은 텍스트의 키워드를 입력하면 검색 결과 UI가 나타납니다. (예: `//분석`)
3. 키보드 화살표(↑, ↓)로 원하는 항목을 선택하고 `Enter` 키를 누르면 해당 텍스트의 내용이 입력창에 자동으로 삽입됩니다.
4. `Esc` 키를 누르면 UI가 닫힙니다.

### 3. 구글 드라이브 백업 (v2.4 New)
1. 확장 프로그램의 **[설정]** 탭으로 이동합니다.
2. '구글 드라이브 백업' 섹션에서 **[연결하기]** 버튼을 클릭하여 구글 계정으로 로그인합니다.
3. **[지금 백업]** 버튼을 누르면 현재 데이터가 구글 드라이브에 `text_saver_backup.json` 파일로 저장됩니다.
4. 다른 PC에서 **[복원하기]** 버튼을 누르면 해당 파일을 불러와 데이터를 동기화할 수 있습니다.

### 4. 웹 페이지에서 직접 저장하기
1. 웹 페이지에서 저장하고 싶은 텍스트를 마우스로 선택합니다.
2. 마우스 오른쪽 버튼을 클릭하여 나타나는 메뉴에서 'Text Saver로 선택 내용 저장'을 선택합니다.
3. 선택한 텍스트가 내용으로, 페이지의 URL과 제목이 메타데이터로 함께 저장됩니다.

### 5. 사이드 패널 사용하기 (v2.4.2 New)
1. 웹 페이지에서 마우스 오른쪽 버튼을 클릭합니다.
2. 'Text Saver 사이드 패널 열기'를 선택합니다.
3. 브라우저 오른쪽에 사이드 패널이 열리며, 팝업보다 더 넓은 화면에서 텍스트를 관리할 수 있습니다.
4. 긴 텍스트 작성이나 많은 항목 검색 시 유용합니다.

### 6. 데이터 관리하기
- '설정' 탭에서 `//` 자동 완성 기능의 사용 여부를 설정할 수 있습니다.
- '데이터 내보내기' 버튼으로 모든 데이터를 JSON 파일로 백업할 수 있습니다.
- '데이터 가져오기'로 백업 파일을 복원할 수 있습니다.

## 🛠️ 로컬 환경에서 설치 및 테스트

1. 이 저장소를 로컬 컴퓨터에 복제(clone)합니다.
   ```bash
   git clone https://github.com/your-username/text-saver-extension.git
   ```
2. Chrome 브라우저를 열고 주소창에 `chrome://extensions`를 입력하여 확장 프로그램 관리 페이지로 이동합니다.
3. 오른쪽 상단의 '개발자 모드(Developer mode)'를 활성화합니다.
4. '압축 해제된 확장 프로그램을 로드합니다(Load unpacked)' 버튼을 클릭합니다.
5. 파일 탐색기에서 이 프로젝트 폴더를 선택하여 로드합니다.

```
└─── js/
     ├─── background.js         # 컨텍스트 메뉴, 단축키 등 백그라운드 로직 처리
     ├─── content.js            # 웹 페이지에 삽입되어 '//' 자동 완성 기능 구현

     └─── popup.js              # 팝업 UI의 모든 기능(저장, 보기, 설정 등) 처리
```

## 🔒 개인정보 처리방침

이 확장 프로그램은 사용자의 모든 데이터를 로컬 컴퓨터의 Chrome 저장소에만 저장하며, 어떠한 정보도 외부 서버로 전송하지 않습니다. (단, 사용자가 직접 구글 드라이브 백업 기능을 실행하는 경우에 한해 사용자 본인의 구글 드라이브로 데이터가 전송됩니다.) 자세한 내용은 [개인정보 처리방침(PRIVACY_POLICY.md)](./PRIVACY_POLICY.md)을 참고하십시오.
